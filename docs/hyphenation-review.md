# Проверка переносов

Выборка для задачи 16 (`research-station/src/library/reader/hyphenate.ts`). Правила переносов взяты из массива `HY` прототипа `preview.template.html`.

**Как собрана выборка.** Скрипт `scripts/hyphenation-sample.ts` читает HTML 68 книг из `../elephantology/dist/library/books/` (сборка задачи 9), прогоняет его через санитайзер и берёт слова из текста, который переносится (то есть без `pre`, `code`, `math`, `sup`, `h1`–`h3`, `.fm`, `[data-note]`). Различных слов из 6 и более кириллических букв — 20389. Из них генератор с зерном **16** выбрал **300** слов (каждая форма слова один раз, в нижнем регистре). Повторить: `npx tsx scripts/hyphenation-sample.ts`. Точка · в таблице обозначает мягкий перенос.

**Как оценивалось.** «Ошибка» — перенос против правил: оставлена или перенесена одна буква, оторваны `й`, `ъ`, `ь` от предыдущей буквы, разорван звук, записанный двумя буквами (`дж`). «Спорно» — перенос формально допустим (слоговой), но идёт не по границе приставки и корня или иным образом неудачен; в счёт порога не идёт, решает автор.

Порог из задачи — больше 6 ошибочных слов (2 %). Ошибок 2, порог не превышен, правила `HY` остаются, переход на шаблоны `hyphen/ru` не нужен. Если автор сочтёт «спорные» ошибками, их будет 18, и порог окажется превышен; тогда переход на `hyphen/ru` стоит рассмотреть.
