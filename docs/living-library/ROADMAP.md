## Принципы

**Неизменные:**
- Текст статей не меняется, меняется только отображение. Авторов и источники не выдумываем, книг-заглушек нет.
- Единственный источник статей — `docs/**/*.md` в Elephantology. Второй системы статей нет.
- Интерфейс на русском. Кампус ведёт себя как раньше: позиция, звук, настройки, здания, список проектов.
- На телефоне не хуже, чем на компьютере.
- Ходить по залу необязательно: до любой книги можно добраться без прогулок.
- Связи с Elephantorina и Keeper Sim выглядят естественно, а не как реклама.
- Цельно и красиво лучше, чем много функций.
- PDF из `docs/assets/books` не публикуются.

**Порядок работы:**
- Push, merge и PR в `main` — только с согласия автора.
- Длинные ветки сливать **merge commit**, не squash: иначе следующий PR из той же ветки конфликтует, как было с elephantology#11.
- Проверки соразмерные: тесты задачи и короткая проверка в Chromium. Без больших синтетических прогонов.
- Одна рецензия на шаг, не на каждую мелкую задачу.
- Сообщения коммитов агентов заканчиваются строкой `Co-Authored-By: …` того, кто писал.

## Как всё устроено

| Часть | Репозиторий | Что делает |
|---|---|---|
| Статьи и данные книг | `elephantology` | `npm run build` в конце вызывает `npm run build:library` (`scripts/build-library.ts`). Он выкладывает `library/catalog.json` (`"elephantology.library/1"`) и `library/books/<cat>/<slug>.json` (`"elephantology.library.book/1"`): 70 книг, это 68 статей, словарь и библиография. Сломанная формула (KaTeX) останавливает сборку. |
| Читалка | `research-station` | `src/library/` — ленивый модуль. `boot.ts` (около 2 КБ) открывает читалку по адресу `#/library/<cat>/<slug>`. Данные берутся с `VITE_LIBRARY_BASE`, по умолчанию `/elephantology/library/`. |
| Кампус | `research-station` | Здания заданы в `src/campusLogic.ts`. Окно здания и список проектов размечены в `index.html`: у здания Elephantology там есть кнопки «Открыть сайт» и «GitHub». |
| Обучение, практика | `elephantorina`, `Elephant-keeper-` | Отдельные сайты, связь только ссылками. |

**Как править статью:** поменять `.md` в Elephantology и слить в `main`. Сайт и книга обновятся сами.

**Проверка локально:**
1. В `elephantology`: `npm run build`, затем `npx http-server dist -p 4320 --cors`.
2. В `research-station`: `VITE_LIBRARY_BASE=http://localhost:4320/library/ npm run dev`.
3. Открыть `#/library/anatomy/muscular-hydrostat-and-trunk-biomechanics` («Хобот»).

**Тесты:**
- research-station: `npm test` (120); `npx playwright test --project=chromium` (37); `npm run build && npm run check:budgets`.
- elephantology: `npx vitest run` (95).

**Бюджеты:**

| Что | Предел | Сейчас |
|---|---|---|
| `boot.ts` | 5 КБ gzip | 2,25 КБ |
| Ленивый код | 60 КБ gzip | около 26 КБ |
| Шрифты книги | 200 КБ | 186020 Б |
| Открытие книги | 600 мс | Chromium 274–388 мс |
| `catalog.json` | 250 КБ сырого, 60 КБ gzip | — |
